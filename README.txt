NOVA — полный комплект: сайт и три кабинета
===========================================

Держите все файлы в одной папке — ссылки между страницами работают по именам.

ПУБЛИЧНАЯ ЧАСТЬ
  nova-agency.html   Главная: оффер, отзывы, прайс по категориям, подписка,
                     работы, блок личного кабинета, о компании, процесс,
                     почему мы, блог, FAQ, квиз-калькулятор, форма заявки
  nova-blog.html     Блог: 30 статей, рубрики, рекомендации, рекламные блоки
  nova-legal.html    Политика конфиденциальности, согласие на обработку
                     данных, публичная оферта — с вашими реквизитами

КАБИНЕТЫ (вход везде по почте + код)
  nova-cabinet.html  Клиент: очередь действий, проекты и этапы, оплата через
                     ЮKassa с привязкой карты и бонусами, приёмка с таймером,
                     ИИ-бриф, документы с подписанием, своя подпись,
                     скидки, партнёрка, профиль. На телефоне — как приложение
  nova-staff.html    Сотрудник: заявки с сайта с кнопками Telegram/WhatsApp/
                     звонок и готовым приветствием, доска производства из
                     5 колонок, клиенты, финансы, документы
  nova-owner.html    Руководитель: пульс и алерты, деньги и дебиторка,
                     трафик и конверсия по источникам, активность команды,
                     клиенты и отток, незакрытые документы, журнал действий

Как открыть: двойной клик по nova-agency.html.
Как выложить: залить все файлы в корень хостинга. Главную можно
переименовать в index.html — тогда в остальных страницах поменяйте
ссылку nova-agency.html на index.html.

ЧТО ОСТАЛОСЬ ПЕРЕД ЗАПУСКОМ
1. Домен. В nova-legal.html есть метка {{ДОМЕН}} (подсвечена жёлтым) —
   встречается в трёх местах.
2. Формы. Заявка и квиз сейчас только показывают сообщение об отправке.
   Подключите обработчик: Telegram-бот, почтовый сервис или форму хостинга.
3. Кабинеты — интерактивные прототипы на демо-данных. Для боевой версии
   нужны: бэкенд и база, ЮKassa (сохранение карт, автоплатежи, чеки 54-ФЗ),
   генерация PDF по шаблонам, почтовый сервис для кодов входа и документов,
   подключение модели для ИИ-брифа.
4. Юридическую часть показать юристу до запуска приёма оплат. В оферту
   стоит добавить пункт о признании простой электронной подписи (63-ФЗ) —
   на ней держится подписание актов кодом из письма.
5. ОКВЭД: основной код 85.41 (доп. образование) не покрывает медиапродакшн
   и разработку. Добавить 59.11, 62.01, 63.11, 73.11 через Госуслуги.
